# 知识库治理

## 分层

本节描述仓库中的 Codex Skill 知识面。Codex 可以按 Skill 工作流读取这些文件；受限 Hermes 关系 profile 当前只自动加载完整 `SKILL.md`，不暴露 `skill_view`、file 或 terminal，因此不能按需读取下述嵌套 reference 正文。

| 层级 | 目录 | 用途 |
| --- | --- | --- |
| 行为规则 | `SKILL.md` | 决定默认谋士循环、行动令、反馈校准和数据输入合同 |
| 核心知识 | `references/knowledge/` | 研究、理论、法律、社会、人文与哲学背景 |
| 实用材料 | `references/practical/` | 沟通结构、情绪回应、拒绝、赞美、主动权和表达脚手架 |

第三方课程与经验资料只按能力原子转译：Hermes 必须执行的任务判断、真实展示、轻调侃、张力、筛选、投入验证和反馈校准进入 `SKILL.md`；机制、证据与失效用法放在 `references/knowledge/`，通用生成规则放在 `references/practical/`。人物姓名、流派模式、课程原文、逐字稿、媒体、版本清单和外部研究工作区不进入运行规则；固定来源版本和许可只在第三方声明中维护。

## 证据等级

1. **较强证据**：元分析、系统综述、大型纵向研究、正式统计和现行法律文件。
2. **理论框架**：可用于提出问题，但不能直接诊断个体或预测结局。
3. **流行说法**：可帮助理解用户语言，必须明确证据局限。
4. **经验策略**：作为可修正的动作线索，根据真实反馈验证，不当作效果保证。

## 包容性要求

- 产品默认主路径可以服务男性自然寻找女朋友；用户身份、目标或关系结构不同时，立即按其实际情况切换，不把默认入口写成普遍性别定律。
- 分开处理性取向、性别身份与关系结构，不混为同一概念。
- 不根据群体身份推断性格、忠诚、性行为或关系能力。
- 对所有关系形式使用同一核心标准：知情同意、互惠、尊重、自主、可靠和修复能力。
- 当地区法律对不同人群保护不一致时，明确区分伦理建议与法律现实。

## 更新规则

- 法律、人口、政策、求助渠道和数字平台信息引用前复核日期与地区。
- 新增研究时优先补充原始或权威来源，不只添加二手总结。
- 修改实用资料时保留“输入信号—当前动作—执行时机—下一节点”结构，不新增固定场景句库或人物模式。
- 新增知识文档时同步必需文件清单或最低数量，不锁死精确总数。
- 删除内容时检查`SKILL.md`路由和所有相对链接。
- 不把真实用户的私密案例直接沉淀进公开知识库。
- Codex Skill 运行面默认按当前问题读取 1–3 份参考；需要证据或风险校准时再增量加载，不批量载入全库。该规则不是当前 Hermes 关系 profile 已实现的 reference 路由能力。
