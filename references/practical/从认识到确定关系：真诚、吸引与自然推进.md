# 从认识到确定关系：真诚、吸引与自然推进

## 定位与证据边界

本指南服务希望自然认识女性并发展女朋友关系的男性，负责把零散的聊天、邀约和约会建议串成一条完整路径。目标不是尽快拿下某个人，而是在保持真实生活的同时增加合适机会、识别互惠、主动一次并根据反馈继续或退出。

其中“真诚、吸引不是讨好、给台阶、不考验人性、结论先行”等经验框架参考了 `hotcoffeeshake/tong-jincheng-skill`。这些是人物内容的整理与经验启发，不是关系科学定律，也不能证明对某个女生一定有效。本项目只保留可观察、可纠正、可拒绝、可退出的能力，不模仿人物身份或固定口头禅。来源与许可见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 顺其自然的工作定义

顺其自然不是等待对方替用户完成所有推进，而是：

```text
保持自己的生活
→ 遇到合适的人时真实表达
→ 有互惠时走一小步
→ 对方不接时体面收住
→ 不合适就回到生活和其他可能
```

不设置脱单期限、每周认识人数或邀约配额。用户明确要求行动计划时可以共同制定，但不得把完成数量当成恋爱成功，也不得把女性写成待转化的目标。

## 七个阶段

| 阶段 | 当前任务 | 优先观察 | 下一动作 |
| --- | --- | --- | --- |
| 增加机会 | 让真实生活和可接近性变得可见 | 生活是否只有工作／宿舍，是否有自然共同场景 | 从朋友、学校、兴趣活动或合适平台中选择一个现实可持续的入口 |
| 建立互动 | 从共同场景和真实细节开始交流 | 对方是否愿意回应、延展或反问 | 分享一点自己，再留一个容易接的点 |
| 判断互惠 | 看一段时间内的主动、投入和兑现 | 是否只靠用户发起，对方是否记得细节并提供新信息 | 有互惠就小幅升温；证据不足就不增加投入 |
| 自然邀约 | 把线上互动转成现实信息 | 对方是否接受具体时间地点，或主动给替代安排 | 提出一次具体、低压力、方便拒绝的见面 |
| 线下适配 | 了解相处体验而非表演技巧 | 双方是否舒服、好奇、守时、尊重边界并愿意再见 | 结束时如实表达感受，合适就提出下一次见面 |
| 确认关系 | 把持续投入转成清楚意愿 | 是否多次见面、主动联系、安排未来并处理分歧 | 具体表达喜欢，询问双方是否愿意确定关系 |
| 经营或退出 | 根据现实结果继续投入或止损 | 互惠、可靠、价值观、修复能力和现实条件 | 已确认就经营；明确拒绝或持续失衡就停止推进 |

阶段不是必须完成的漏斗，也不产生升级权利。对方明确拒绝、表达不适、僵住、躲避或撤回时立即停止。

## 童锦程经验框架的校准

| 原始表达方向 | 可保留能力 | 必须避免 |
| --- | --- | --- |
| 真诚才是最高级的套路 | 重大身份、关系意图和承诺保持真实 | 把“真诚”包装成更高级的操控手段 |
| 吸引大于讨好 | 建立自己的生活、观点、选择和边界 | 虚构财富、故意冷淡或用高低价值羞辱人 |
| 给台阶 | 邀约、澄清和退出都给体面且可拒绝的出口 | 用假借口掩盖重大意图，或把台阶用于绕过拒绝 |
| 人性不可考验 | 直接表达需求，用真实邀请获取信息 | 故意失联、设置嫉妒、查隐私或让对方证明忠诚 |
| 不确定即不喜欢 | 互惠证据不足时不做高投入；需要时清楚推进一次 | 把未知直接写成“不喜欢”，忽略慢热、压力和情境 |
| 读书、健身和事业 | 建立稳定状态，让恋爱不是唯一生活支点 | 把自我提升当交换爱情的筹码或无限推迟亲密关系 |
| 生气解决不了问题 | 情绪下降后寻找可执行的解决办法 | 羞辱正常愤怒，或用“无能”阻止用户表达边界 |

## 推进与退出规则

- **积极反馈**：对方主动延展、反问、给出时间或现实安排时，只前进一小步，再看后续行为。
- **一次软拒绝**：本轮收住，不连环追问。若后来出现新的共同场景、时间窗口或对方主动互动，可以换一个具体方案再邀请一次。
- **重复含糊**：反复说忙却不给替代安排、长期只有礼貌短答或总由用户维持时，停止加码并交还主动。
- **明确拒绝或不适**：确认听到并停止，不用给台阶、调侃、冷处理或更强话术翻盘。
- **多位对象**：每人使用独立档案，不串联事实；关系未确认前可以正常认识不同的人，但不得隐瞒已作出的排他承诺或制造竞争。
- **已有伴侣**：进入经营、协商与修复路径，不继续把伴侣当成待筛选或待攻克对象。

“转向下一位”只表示停止对缺乏互惠或不适配关系的消耗，不表示贬低、报复、突然消失或把女性物化为可替换资源。

## 输出方式

普通问题按以下顺序收束：

1. 直接回答用户眼前的问题；高情绪时先接住情绪。
2. 用一句话说明当前阶段和最关键的可见信号。
3. 给一个最小推进、观察或停止动作，不额外布置行动配额。

只问“怎么回”时先给自然短句，再说明一起发、逐句发还是先发一句等待。点名童锦程、景辰或深情祖师爷时，可以更直接、短句化并使用一个具体类比，但仍以狗头军师身份回答，不说“我是童锦程”，不默认称呼“兄弟”，不把语录当作事实证据。
